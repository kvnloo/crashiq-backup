Maryland: the open statewide data is gone

In one line: Maryland's open statewide crash table now asks for a login. The State Police still show every crash on a public dashboard you can download from by hand, but there's no way for CrashIQ to pull it by itself. So no Maryland pack yet.

1. What changed

On 2 Nov the open table (opendata.maryland.gov, "Maryland Statewide Vehicle Crashes") was listed as open. Today every request answers You must be logged in to access this resource.

2. What still works

SourceWhat you get
State Police dashboard (2019–now)Every crash, by hand: pick a date range, click the map, Download → Data, five tabs. No login. No licence found.
Same dashboard, scriptedOnly report number + map point (110,474 crashes): no date, injury or road.
Montgomery CountyOpen, public domain, ~10,000 crashes a year with road, cross street and map point. One county only.
SHA fatal crashes269 fatal crashes on state roads. Fatal only.

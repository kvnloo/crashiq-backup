Florida: what crash data we can use

Checked 7 Nov 2026. Every number below was counted by code. Full notes: fl-import.md, rules and costs: fl-methods.md.

Short answer: Florida's real crash database (Signal Four) is locked to agencies and the consultants they approve. Your users have it, so CrashIQ should read the file they download from it. Free public files exist, but none says we may use it in a paid product.

1. The data

  1. Signal Four Analytics (S4): FDOT's official crash system. It has every crash with street names, its own map point, and the injury level. Login only: FDOT staff, agencies, universities and approved consultants.
    Every FDOT manual says to use S4. The design manual says: use "all location verified statuses (i.e. verified as well as preliminary)".
  2. State crash file from FLHSMV (free download): 700,000 crashes a year, 2023 to March 2026. 3 of 4 have a map point. None have street names.
    2025: 687,313 crashes; 514,659 have a map point. The other 172,654 only say the county, so nobody can place them.
  3. Copies of S4 that regions put online (free): Palm Beach (268,619 crashes, 2019–2024), Orlando region (526,438, 2018–2025), City of Orlando, Hillsborough, Jacksonville. They have street names and S4's map point. None gives permission for paid use.
    Palm Beach's copy only says "no warranties". It has no report number, so it can't be matched to the people in each crash.
  4. Big cities: Miami-Dade and Tampa publish only deaths and serious injuries (9,468 and 1,497 crashes). No city has a full open crash table like New York's.

2. Can CrashIQ put crashes on the map itself?

We took 2,000 Palm Beach crashes from 2024, hid S4's map point, and let CrashIQ place them from the street names on the report, using the Census street map.

Here this adds no new crashes, because S4 already maps them all. It matters as a check on S4's point, and for exports that come without S4's point.

3. Florida's rules (not California's)

  • Crash costs (FDOT Design Manual 2026): fatal $10,890,000, serious $888,030, moderate $180,180, minor $103,950, damage only $7,700.
    California prices fatal and serious together: $2.4M–$3.8M. A Florida fatal crash counts about 4.6 times as much.
  • Years: 5 full calendar years ("shall", for the HSM method).
  • High-crash test: FDOT compares a site's rate to the average for the same kind of road in its district, and reports how sure it is (50% to 99.99%).
    FDOT doesn't publish those averages. There's no table like California's TASAS rates.
  • Preferred method: HSM predicted crashes with Florida's own adjustment numbers (e.g. urban 4-lane divided ×1.63).
  • Forms: FDOT collision diagram and collision summary forms (750-020-05i/j/k).
  • New: FDOT stopped its intersection control evaluation (ICE) program on 2 Nov 2026.

4. What we built

Two readers, tested on saved samples: one for an S4 download (it also reads the regional copies), one for the state FLHSMV file. They aren't connected to the app yet.

What you need to do

  1. Get one S4 download through an FDOT project manager: Palm Beach County, 2024, the crash "Event" file as CSV. That shows whether our reader matches the real file.
  2. Email FLHSMV Crash Statistics (850-617-3105) and ask if their free crash file can be shown in a paid tool.
  3. Decide: Florida as "bring your S4 file" only (recommended), or also the free regional copies for Palm Beach and Orlando.

What we didn't check

  • FDOT's own map server (it was down that day).
  • A real S4 download (we built the reader from S4's public field list).
  • Whether S4's points are accurate. We compared against them, but S4 doesn't check every point by hand.
  • Street-name placement limited to each city (we used one map for the whole county).
  • Florida's average crash rates (not public). Address lists for counties other than Palm Beach.

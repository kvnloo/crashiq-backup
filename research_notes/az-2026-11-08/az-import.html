Arizona: crash data for CrashIQ

Hermes, 8 Nov 2026. Checked live today. Full notes: az-import.md, column map: az-column-map.json.

Short answer: Arizona is locked. ADOT's crash records need an ACIS account (an agreement with ADOT plus a signed NDA) or a public-records request. We built no pack. Tempe's open data shows ADOT's format places well: 91% within 250 ft near intersections.

1. What Arizona has

  • ADOT ACIS: every crash in the state, mapped, KABCO, exports as CSV. Needs an inter-governmental agreement with ADOT, an NDA and a use agreement.
  • ADOT public records: you can ask for the same data with an account at azdot.govqa.us.
  • ADOT's open files are yearly PDF reports and dashboards (totals, not crashes), plus fatal/serious maps that stop in 2016.
  • Tempe (one city): 59,094 crashes 2012-2026, GPS on almost all, free with credit (CC BY 4.0). Example: "McClintock Dr, 333 ft from Broadway Rd, suspected minor injury".

2. Would CrashIQ place the crashes?

  • On 2,000 Tempe crashes from 2025, we hid the GPS and placed them from the street names: 86% placed.
  • Within 250 ft of the true spot: 73% overall, 91% for crashes within 250 ft of the intersection. Tempe's copy gives the distance but not which way, so far-off crashes land at the corner.
  • What fails: landmark "streets" like "Tempe Marketplace".

3. What you need to do

  1. Choose: get an ACIS account (ask ADOT at JPABranch@azdot.gov for an agreement, then the ACIS form with NDA and use agreement), or file a public-records request for statewide 2020-2024 crash, vehicle and person files with coordinates.
  2. Read the use agreement: can the data be used inside a paid tool?
  3. Send us one ACIS export (one county, one year) so we can confirm the column map and build the upload.

4. What we didn't check

  • ADOT's NDA/use-agreement text and HSIP manual (azdot.gov blocks automated downloads).
  • Phoenix, Mesa, Chandler, Tucson: no open crash tables found.

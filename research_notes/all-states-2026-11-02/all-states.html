CrashIQ: every state, by import method

Screened 2026-11-02 (50 states + DC). Your order: #1 NY → #2 TX → #3 WA/Seattle → #4 FL → rest. Commercial-use licence unconfirmed almost everywhere (only Iowa CC BY, DC CC0, NY OPEN-NY).

A · Open and ready 14

Read straight from the state's site, like California. Build: one reader per state.

  • California
    Active pack (CCRS).
  • Colorado
    Statewide listings, 407 notice.
  • Connecticut
    UConn CTSRC's public ArcGIS MapServer has Crash (1,221,480), Person (2,863,884) and Vehicle layers, maxRecordCount 2,000, with no login. CTCDR web tool and CTDOT open-data crash layers are also available.
  • Iowa
    Crash_Data FeatureServer (639,375 crashes) has CSEV 1-5 (1=K..5=O; K 3,611 / A 13,859 / B 59,071 / C 101,617 / O 461,216), CRASH_KEY links to Crash_Person_Data (640,188) and Crash_Vehicle_Data (1,099,571, VEH_CRASH_KEY). Street name in LITERAL field. maxRecordCount 2000 means paging; Extract capability enabled. ICAT (icat.iowadot.gov) is the analyst UI, limited to 500/50 crashes per list.
  • Kansas
    KDOT 'Crashes in Kansas' FeatureServer (607,184 rows, state system Y 223,792 / N 383,392, so local roads included). ACC_SEVERITY is only FATAL/INJURY/PDO, but per-crash counts FATALITIES, DISABLING_INJURIES, NON_INCAPACITATING_INJURIES, POSSIBLE_INJURIES give K/A/B/C. No person/vehicle tables; ACCIDENT_KEY + REPORT_IMAGE_LINK present. Full detail (KCDS) needs agency login or open-records request.
    City data: [{'city': 'Wichita', 'url': 'https://gismaps.wichita.gov/ageweb/rest/services/OpenData/TrafficAccidents/FeatureServer', 'note': 'yearly layers 2018-2026 + All; fields not checked'}]
  • Maine
    Hosted feature layer 'MaineDOT Crash Locations - 10 Years Complete' (layer 44, 112 fields incl. traffic control, speed limit, contributing factors, AADT). 1/3/5-year and current-year views also exist. The old gis.maine.gov MaineDOT_OpenData_Crashes MapServer now returns no layers.
    City data: Portland area via GPCOG (derived from the state tool): https://services6.arcgis.com/HvbabY0grzgZwGW1/arcgis/rest/services/Maine_Public_Crash_Query_Tool_High_Crash_Locations_2026_06_03/FeatureServer
  • Maryland
    Statewide record-level ACRS data is downloadable without login from MSP's public Tableau (analytics.mdsp.org guest view), but only by manual 'Download > Data' clicks (UTF-16 tab-separated files), no API. Montgomery County has a true open API with GPS. Confirm export columns include lat/long and licence before building.
    City data: [{'city': 'Montgomery County (county/local roads only)', 'url': 'https://data.montgomerycountymd.gov/Public-Safety/Crash-Reporting-Incidents-Data/bhju-22kf', 'note': 'Socrata API, ~10-12k crashes/yr 2015-2026, lat/long, road_name + cross_street_name; drivers mmzv-x632, non-motorists n7fk-dce5'}]
  • Massachusetts
    MassDOT IMPACT ArcGIS; AADT joined; licence: ask MassDOT.
  • Minnesota
    DPS MnCrash 'Public Crash Data Portal' lets anyone query and export CSV (no login), and 'complete public crash data sets' are offered by email (MNCrash.Team@state.mn.us). It is an ASP.NET query UI, not an API. MnCMAT2 (better mapping/analysis) is gated to MN county/city staff and contracted consultants with an engineer sponsor.
  • Mississippi
    DPS public data posts one xlsx per year (2024 = 99 MB) with sheets Crashes, Drivers, Passengers, Non-Motorists, Vehicles, linked by Crash ID (GUID). Person 'Injury Status' is KABCO ('(K) Fatal Injury' ... '(O) No Apparent Injury'); crash severity must be derived from the worst person. 74,968 crashes in 2024; whether all agencies report via eCrash is UNVERIFIED.
  • Oregon
    The OTSDE_Crash ArcGIS MapServer is public: 273,810 crashes, KABCO, lat/long and milepoint, maxRecordCount 10,000. ODOT also posts downloadable Access decode databases and crash geodatabases on CrashDataProducts.aspx.
  • Pennsylvania
    Public annual downloads, no login; licence UNVERIFIED.
  • South Dakota
    Two public SDDOT layers from SDARS: HY11_IntersectionCrashDiagram (2004-2026, 399,194 rows, richer fields incl. FuncClass, speed limit) and TIM/DOT_Crashes (2022-2026, 84,653). InjurySeverity uses KABCO names (Fatal/Incapacitating/Non-incapacitating/Possible/No injury) but also 'Wild animal hit' (19,690 in DOT_Crashes) as a value - needs mapping. Flat crash rows with first-driver fields; no separate person table; maxRecordCount 3000 so page queries. Old safesd.gov raw-data zips (2008-2017) now 404.
  • Utah
    UDOT's public 'Utah Crash Locations' FeatureServer (maxRecordCount 2,000, Query+Extract) is the best open source in this group, but it has no person/vehicle tables. Check why the 2025 layer is short before use. There is also a Socrata 2015-2019 dataset at opendata.utah.gov (7ihm-46s4).
    City data: [{'city': 'Salt Lake City', 'url': 'https://maps.slc.gov/server/rest/services/Hosted/SLC_Crash_Data/FeatureServer', 'notes': 'SLCPD crash points, snapshot dated 2023-03-13'}]

D · Gated 23

Agencies/consultants only, or by request. Build: 'upload your export'. FARS fatal crashes meanwhile.

  • Alaska
    Only public record-level data is AKDOT_GIS 'Crash_2023Table' (no coordinates, no crash ID, severity only as serious-injury/fatality flag). Anything usable comes from the crash data team (dot.crash.info@alaska.gov), so users must bring their own export. Anchorage crash open data not found.
  • Arizona
    Public Record Center only.
  • Georgia
    GDOT Numetric dashboard; custom data by email.
  • Hawaii
    The statewide crash system (SHACA, built from county police MVARs) is internal. The public CARTO 'Safety Analytics' platform shows crash maps, but no record-level download was confirmed (UNVERIFIED). Use FARS as the public fallback for fatal crashes.
    City data: Honolulu 'Traffic Incidents' (ykb6-n5th) is a 24-hour police dispatch feed (date, type, address; 164 rows), not crash reports: https://data.honolulu.gov/Public-Safety/Traffic-Incidents/ykb6-n5th
  • Illinois
    IDOT Safety Portal needs County Engineer vetting.
    City data: Chicago (85ca-t3if): 1,108,694 crashes, 99.2% GPS, to 2026-10-30 (checked 2026-11-02)
  • Indiana
    ARIES (LexisNexis) is government-only; INDOT's crash analysis runs in AASHTOWare Safety via an Access Indiana/ITAP account that external users may request (approval criteria UNVERIFIED). The public ARIES download is a 17 KB yearly statistics zip, not records; Indiana MPH data hub has no crash dataset.
    City data: [{'city': 'Indianapolis region (IMPO)', 'url': 'https://indympo.gov/regional-insights/crash/', 'note': 'F&I crash dashboard only; record download UNVERIFIED'}]
  • Louisiana
    LSU CARTS manages the data for DOTD. The public sees only dashboards and reports. Record-level access goes through the DOTD Louisiana Crash Tool (LCT) or by emailing DOTDCrashData@la.gov. Baton Rouge open data is the only public record-level GPS source found.
    City data: [{'city': 'Baton Rouge', 'url': 'https://data.brla.gov/Public-Safety/Baton-Rouge-Traffic-Crash-Incidents/7wah-qncc', 'notes': 'Socrata, licence Public Domain, latitude/longitude, has_injury/has_fatality flags (not KABCO); about 15k rows/yr 2023-2025, starts mid-2022'}]
  • Michigan
    MTCF query tool; confirm export.
  • Missouri
    Public side is MSHP STARS statistical reports plus a 'Traffic Crashes Online Mapping' tool (whether it exports record-level rows is UNVERIFIED) and MoDOT dashboards. MoDOT's only public crash point layer is the 2014-2023 wildlife-collision subset (BusinessInt/WVC), which shows the internal data has milepost + lat/long + severity. Treat as bring-your-own-export unless MoDOT/MSHP confirm a bulk release.
    City data: [{'city': 'Kansas City', 'url': 'https://data.kcmo.org/d/62pj-bjfw', 'note': 'MSHP STARS exports, injury/fatal only, 2019-2024 (~5k/yr), on_street/at_street, no coordinates, no PDO'}]
  • Nevada
    NDOT's Crash Data Web Map is 'under construction and temporarily unavailable'; statewide data must be requested via a Survey123 form. No public record-level statewide layer found on NDOT GeoHub. Las Vegas city feed exists but ends 2020.
    City data: [{'city': 'Las Vegas', 'url': 'https://services1.arcgis.com/F1v0ufATbBQScMtY/arcgis/rest/services/Traffic_Crashes/FeatureServer/0', 'note': '70,888 polygon-geometry (null geometryType) rows, 2015-2020 only, primary/secondary street + distance; stale'}]
  • New Hampshire
    NHDOT Highway Safety Office takes outside requests through a 'Safety Evaluation for External Request: Crash Data and Safety Concerns Report' form. The DMV sells single reports ($1/page, $5 minimum). RPCs (e.g. SWRPC) use NHDOT GIS crash data, so an agency/consultant export exists.
    City data: none found
  • New Jersey
    2019+ only via Numetric dashboard; Safety Voyager gated.
  • New Mexico
    Record-level data only via NMDOT Crash Data Request Form; UNM-GPS publishes reports, dashboards and PDF/interactive maps. Public NMDOT ArcGIS has subsets only (VRU crashes 2013-2023, I-40 crashes 2016-2021) - not usable for general corridor studies. No Albuquerque open crash feed found (MRMPO layers are 2013-2018 smoothed/aggregate).
  • North Carolina
    TEAAS for government/research.
  • North Dakota
    No public record-level crash dataset found on NDDOT or ND GIS Hub. NDDOT Traffic Operations Manual: 'NDDOT will provide the crash data per the developer's request'; individual reports are purchased. (Note: geohub-ndot 'CrashData OpenData' is Nevada DOT, not ND.)
  • Ohio
    GCAT for agencies and pre-qualified consultants.
  • Oklahoma
    ODOT crash data sits in SAFE-T (login at oksafe-t.org) and ODOT's Numetric Crash Query, which both need accounts. OHSO publishes only dashboards, story maps and Crash Facts PDFs, plus a few 2019 OHP-only ArcGIS layers.
    City data: [{'city': 'Oklahoma City', 'url': 'https://services5.arcgis.com/2mOVdIcRtNH2JsSF/arcgis/rest/services/OKC_Crash_Map_WFL1/FeatureServer/0', 'notes': 'Vision Zero layer, 49,249 crashes with lat/long, severity and on/at street. Dates run 2017-01-01 to 2021-12-31 (static snapshot)'}]
  • Rhode Island
    RIDOT refused to release crash data until the June 2026 law made it a public record. Now it can be requested under APRA. Re-check for a RIDOT portal: one could move RI to A or B.
    City data: Providence: PVD Crash Map by Providence Streets Coalition, built from Providence PD records (community, not official): https://pvdstreets.org/crash-map/
  • South Carolina
    SCDPS is custodian of the master crash file; public output is fact books, a fatality dashboard and statistics on request (non-media requests go to OHSJP). No record-level public download or portal found. SCDOT consultants would need an agency-provided export.
  • Tennessee
    Full TITAN data is LE-only; consultants need a records request or agency export. A public, queryable ArcGIS layer (tnmap.tn.gov SAFETY/MapForDashboards/MapServer/0) gives GPS-placed fatal+injury crashes since 2024 with flags (ped, bike, speed, DUI) but no KABCO or PDO, usable as a limited Part A.
    City data: [{'city': 'Nashville (Metro)', 'url': 'https://data.nashville.gov/datasets/Nashville::traffic-accidents/explore', 'note': 'ArcGIS FeatureServer Traffic_Accidents_2, 222,903 rows 2019-01-01 to 2026-10, Lat/Long, street address, injury/fatality counts incl. PDO, no KABCO'}]
  • Washington #3
    WSDOT record-level by request (~10 days).
    City data: Seattle (SDOT Collisions, 2004-present, weekly; severity 3/2b/2/1/0)
  • West Virginia
    WVDOT's Traffic Accident Data page only says to email a named contact (Marsha.K.Mays@wv.gov). No crash layer found on the WVDOT open data portal or ArcGIS Online. MPOs (e.g. MMMPO) get data from WVDOT, so consultants can get exports.
    City data: none found
  • Wyoming
    Public side is a standard crash-counts report (statewide/county/district, 8 topics) and a fatal-crash web app; detailed data only via WYDOT Highway Safety crash data request form. Users would upload a WYDOT export; FARS covers fatal only.

# Run 10: GPS repair, TIGER names on, approximate freeways (2026-10-25)

Tester session, measure only. App code: main 2d110db, which has #250, #251, #252, #254 and #258 (TIGER union on,
`freeway_offset` auto with provenance approximate, `freeway_move_gps` off). Basis: CCRS mirror 2026-10-19 +
Parties_2025 file, OSM 2026-10-18, TIGER/Line 2026. Harness:

```
coverage.py --network box1km --aliases --rule2 --tiger --run10
```

Completeness: all 2,057,508 crashes in run 9C and run 10.

**Correction, 2026-10-25 (run 10b).** Engineering (#259) found a defect in the first run-10 harness. `fwy_raw.py`
looked up the reference street by exact name core, without `alt_name`, so OSM streets named with a leading direction
word ("South Normandie Avenue" for "NORMANDIE AVE") were missing from the raw `freeway.place` saw. The app's
`same_core` treats them as one street, so mainline and ramp placements were understated. The fix: the street is
indexed with and without the leading direction word, over name, alt_name and ref. Run 10b redoes only the freeway
step (`run10_fwy_redo.py`): the 25,000-odd freeway crashes without fitting GPS or an exact / unique_pair placement.
In run 10b, 318 more no-GPS and 1,029 more GPS-off-roads crashes get a spot, and 497 run-10 spots go. With every
crossing street in the raw, those 497 meet the freeway in more than one place.

Connectors are unchanged: for "X TO Y" `freeway.place` never reads the reference street. Everything else is unchanged
too (GPS repair, intersection accuracy). The figures below are run 10b's. The first version's are kept in
`run10_reconcile.json` / `approx_accuracy_r10v1.json`.

Harness for the new code (`tests/statewide`):
- **#251:** when a point doesn't fit, the DMS reading is tried for every agency, per crash. A crash outside the #143
  agency-years is recorded as `dms_new`. A positive longitude whose minus restored lands in California and fits the
  report becomes `gps_usable_sign` (raw mirror values).
- **#258:** a freeway crash the locator doesn't auto-place goes to the app's `freeway.place`. Its raw elements come from
  `fwy_raw.py`: the route's lanes in the county, links within 6 hops, and the reference street (city box + 1 km when
  in a city, else the county).
- **Counted as the app does it (PM 2026-10-25):** approximate = crashes with no usable GPS. A freeway crash whose GPS
  is off its roads keeps the officer's GPS in the app, so its report spot isn't counted. It's listed below as "not in
  the app" and keeps its run-9C outcome.

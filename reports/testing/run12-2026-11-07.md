# Run 12: statewide placement with county address points and private-property addresses (2026-11-07)

Tester session for #393 and #397, measure only. App code: main eb9e478. Placement changes since run 11 (c53b23a): #399 county address points where NAD has none (Los Angeles and San Diego place by themselves; Orange, Fresno, Riverside and San Joaquin only suggest a point for review), #402 PRIVATE PROPERTY with a house address on the street placed at that address, #391 'Unnamed road' corridor pieces (corridor only, nothing to measure statewide). Basis as run 11: CCRS mirror 2026-10-19, OSM 2026-10-18, TIGER/Line 2026, NAD r24; county points downloaded 2026-11-06. Harness:

```
coverage.py --network box1km --aliases --rule2 --tiger --run12
```

`--run12` = `--run11` plus two fixes so the harness measures the app: house addresses are read with the app's own parser (`crashes.house_address`; run 11 used a stricter look-alike and missed some, PR #392), and an address point places only when its source is set to place by itself (`nad.auto_sources()`).

Statewide there is no drawn corridor, so a house-address crash counts as on the map when an auto-source point is found under the app's rules (house number, street, city). The app's setback cap (a point too far off the corridor line isn't used) needs a corridor, so it can't be applied here: a few of these crashes could still be refused in a real study.

Completeness: all 2,057,508 crashes in run 11 and run 12.

Public Tools Can Replace Some Locator Code, but Only TIGER Travels Cleanly to Every State

Issue #20 (feeds #18 and #19) · Hermes · researched 2026-10-18 · status: research only, nothing here is decided

The user asked for proven public tools so agents stop re-inventing address handling. This report covers the non-code side: licence, hosting cost, nationwide fit and upkeep. Claude Code's bake-off on the hidden-GPS tests (Long Beach, SF) answers the accuracy question; until it reports, nothing here says any tool beats our locator. Licences are not the problem. Every tool's code is MIT, Apache or GPL, and all of these can run inside a hosted paid product. The data is public domain (Census TIGER) or ODbL (OpenStreetMap: attribution required, no share-alike for individual geocodes). Cost and fit are the real differences. usaddress is a few MB of pure Python, handles "street & street" intersections and can be retrained on our own labelled crash strings. libpostal is more accurate on postal addresses (99.45% claimed) but needs a 1.8–2.2 GB model and about 4 GB of RAM, which means an $85/month Render instance instead of $25. Census TIGER/Line is the only street network built the same way in all 50 states, with no copyright. California's geocoder layers are 1.22 GB zipped. Nominatim can't search intersections at all, and Pelias needs an Elasticsearch cluster, so neither fits the core job. The nationwide limit comes from the crash data, not the tools: NY, WA, TX and FL often locate crashes by route and milepost or reference marker, which no parser or geocoder here handles.

Method. Licences and activity were read from the GitHub API and PyPI on 2026-10-18. Docs, usage policies and pricing come from primary pages, cited inline. TIGER sizes were summed by script from the Census TIGER2026 directory listings (research_notes/tools-2026-10-18/tiger2026_sizes.json). Anything not confirmed from a primary source is marked UNVERIFIED. Render prices are list prices on 2026-10-18.

Already in our stack: OSM through Overpass. backend/crashiq/osm.py calls the public Overpass server. Its guideline is about 10,000 requests and 1 GB a day (Overpass): fine for development, wrong for a paid product. Production would load Geofabrik extracts instead (California 1.26 GB, US 11.4 GB .osm.pbf, Geofabrik). It must also show "© OpenStreetMap contributors" on maps and exports.

Nationwide fit: the tools are national, the crash locations aren't (#4, #18, #19)

usaddress, libpostal and TIGER cover every state, DC and Puerto Rico the same way. OSM street naming and completeness vary by region, while TIGER is built by one agency to one schema. What changes by state is how the crash record says where it happened (from the #4 matrix):

Recommendation (Hermes's view, for the user to decide)

  1. Parsing: usaddress first. It costs nothing to host, it understands intersections, and it can learn CCRS-style strings from our own labels (only with the user's approval, per CLAUDE.md). Take libpostal only if the bake-off shows a clear win over usaddress, because that win would cost about $60/month and a model we can't retrain. Use scourgify only for the house-address tier.
  2. Street network: plan on TIGER as the nationwide backbone, next to OSM. It is public domain, carries no attribution or share-alike duty, and is built to one schema in every state. Whether we use it through PostGIS Geocode_Intersection or load the TIGER files into our own locator depends on the bake-off. If PostGIS doesn't clearly win, loading TIGER into our locator keeps the SQLite stack and avoids a Postgres bill.
  3. Not for the core: Nominatim (no intersection search), Pelias (cost and upkeep), the public Nominatim server (usage policy). The Census Geocoder API is a free option for the house-address tier only.
  4. Before any paid launch: move OSM from public Overpass to Geofabrik extracts, and add OSM attribution to the UI and exports.

Conclusion

Licences don't block any of these tools in a hosted paid product. What separates them is cost, fit to crash strings and the nationwide story. usaddress is the cheap, trainable parser. TIGER is the only street data that is free of obligations and the same in every state. The heavyweight geocoders (Nominatim, Pelias) don't solve the intersection problem CrashIQ actually has. Claude Code's bake-off decides on accuracy; the user decides on the questions above. Outside California, much of the location work in NY, WA and parts of TX/FL is milepost conversion, which belongs in each state pack, not in a parsing library.
